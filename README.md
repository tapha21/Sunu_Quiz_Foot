Ce projet est un jeu de quiz sur le thème du football.
Avant de jouer, l'utilisateur doit se connecter avec un nom d'utilisateur et un mot de passe.
Le quiz contient des questions à choix multiples.
Chaque bonne réponse permet de gagner des points.
À la fin du jeu, le score est affiché et enregistré dans une base de données.
Connexion obligatoire pour accéder au quiz.
Une seule bonne réponse par question.
Le score s'accumule automatiquement.
À la fin, le score est visible.
