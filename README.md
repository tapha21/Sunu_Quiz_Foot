cette application est un jeu de quiz sur le thème du football.Avant de jouer, l’utilisateur doit se connecter avec un nom d’utilisateur et un mot de passe.Deux utilisateurs par défaut sont créés :
tapha avec le mot de passe 123,talla avec le mot de passe 123
Le quiz contient des questions à choix multiples, avec une seule bonne réponse par question.
Chaque bonne réponse permet de gagner des points.Le score s’accumule automatiquement au fur et à mesure des réponses.À la fin du quiz, le score est affiché et enregistré dans une base de données SQLite.La connexion est obligatoire pour accéder au quiz.
